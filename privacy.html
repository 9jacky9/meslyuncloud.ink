隐私政策 (Privacy Policy)

MESL Cloud 机场始终将捍卫用户的数字主权与个人隐私视为最高戒律。本隐私政策阐明我们在技术机制与服务运营中恪守的严苛隐私承诺。

【金石为证 · 严守无日志】：MESL Cloud 机场严格践行“绝对无日志记录 (Strict No-Logs Policy)”底线原则。我们绝不记录、绝不保存、绝不追踪、绝不出售任何用户的网络访问活动日志！

一、 坚决杜绝采集的数据

基于我们自主构建的内存级专线分流与无盘化转发架构，下列任何涉及个人网络轨迹的数据在物理底层均无从留存：

  • 浏览历史与目标网址：不保存用户访问过的任何域名、IP 或网页内容。
  • 通信数据与应用负载：所有跨域流量均经高强度多层加密封装，服务器仅执行无状态转发，不留存任何通信报文。
  • 用户原始源 IP 地址：用户接入节点时，瞬时连接状态仅存于内存会话，连接闭合即物理销毁。
  • DNS 解析记录：全站使用内嵌私密 DoH/DoT 加密 DNS 递归集群，彻底封堵任何外部嗅探通道。

二、 仅维持运作的基础数据

为支撑套餐订阅的正常流转与计费周期，我们仅在数据库中保存以下最小化信息：

  • 用户注册邮箱账号（用于凭据找回与关键业务通知）。
  • 套餐订阅有效期限与当前周期已消耗总流量（纯数字指标，与访问行为解耦）。
  • 当前实时并发连接数（仅用于防止超出套餐额定设备数）。

三、 数据传输与加密规范

所有骨干信道均采用前向安全密钥协商机制与现代对称加密算法，确保即便在复杂网络环境下传输，用户数据亦如深潜暗涌，万无一失。
